# موقع خضره وفواكه الشرج

موقع طلب بسيط من جزئين:

- **صفحة الزبون:** `index.html` (المنتجات والسلة، والطلب يوصل واتساب).
- **لوحة التحكم:** `admin/index.html` (إضافة وحذف وتعديل المنتجات والأسعار والإعدادات، ثم نشر مباشر).

بيانات المحل كلها في ملف واحد: `data/store.json`. لوحة التحكم تعدّل هذا الملف وتنشره عن طريق GitHub، وما تحتاج تلمس الملفات بنفسك.

## أولاً: الرفع على GitHub (مرة واحدة)

1. ادخل على github.com وسجّل حساب لو ما عندك.
2. اضغط **New repository** (مستودع جديد). اكتب اسم بالإنجليزي مثل `alsharj-fresh`، واختر **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، ثم اسحب كل محتويات هذا المجلد: `index.html` و`admin` و`css` و`js` و`data` و`images`. تأكد أن المجلدات ظهرت كلها، ثم اضغط **Commit changes**.
4. افتح **Settings**، ثم **Pages**. تحت **Branch** اختر `main` و`/ (root)`، ثم **Save**.
5. انتظر دقيقة أو دقيقتين. يظهر لك رابط الموقع بهذا الشكل:
   `https://اسمك.github.io/اسم-المستودع/`

## ثانياً: مفتاح التعديل (مرة واحدة)

لوحة التحكم تحتاج مفتاح خاص منك عشان تقدر تحفظ في مستودعك.

1. في GitHub: الصورة الشخصية، ثم **Settings**، ثم **Developer settings**.
2. **Personal access tokens**، ثم **Fine-grained tokens**، ثم **Generate new token**.
3. **Repository access:** اختر **Only select repositories** وحدد مستودع المحل فقط.
4. **Permissions**، ثم **Repository permissions**، ثم **Contents**، واختر **Read and write**.
5. حدد مدة الصلاحية (مثلاً سنة)، ثم **Generate token**، وانسخ المفتاح (يبدأ بـ `github_pat_`).

## ثالثاً: الدخول والتعديل

1. افتح رابط الإدارة:
   `https://اسمك.github.io/اسم-المستودع/admin/`
2. الصق المفتاح واضغط **دخول**. اسم المستخدم والمستودع يتعبّون تلقائياً.
3. عدّل ما تحتاج:
   - **تحديث الأسعار:** سعر اليوم وحالة التوفر.
   - **المنتجات:** إضافة وحذف وتعديل، ورفع الصور.
   - **الأقسام:** إضافة وحذف وترتيب.
   - **إعدادات المحل:** رقم واتساب، التوصيل، الحد الأدنى للطلب، ساعات الدوام، وفتح وإغلاق المحل.
4. اضغط **حفظ ونشر**. تظهر التعديلات للزبائن خلال دقيقة تقريباً (وقت تحديث GitHub Pages).

أول شيء سوّي: ادخل **إعدادات المحل** وضع رقم واتساب الطلبات، وعدّل المنتجات التجريبية بمنتجاتك وأسعارك.

## الصور

كل صورة ترفعها تتقص تلقائياً مربعة من الوسط بمقاس موحّد (600 × 600)، فتظهر متناسقة داخل بطاقات العرض. اختر صورة المنتج في وسطها.

## ملاحظات مهمة

- **المفتاح سري.** لا تشاركه مع أحد ولا تحطه في أي ملف. يتحفظ في متصفح جوالك أو جهازك فقط، وزر **خروج** يمسحه.
- لو ضاع المفتاح أو انتهت صلاحيته، احذفه من GitHub وأنشئ واحد جديد.
- رابط الإدارة غير مرتبط من صفحة الزبون، لكنه ما يحتاج سرية: بدون المفتاح ما أحد يقدر يعدّل.
- أرقام الجوال: اليمنية `7XXXXXXXX` والسعودية `5XXXXXXXX`.
- لو عدّلت من جهازين بنفس الوقت، تظهر رسالة تطلب تحديث الصفحة قبل الحفظ.
